# Juegos de PlayBox

Rama solo de descargas: aquí están los APK y los zip para PC de los juegos propios (Zona Cero…),
troceados en partes de menos de 100 MB. PlayBox Control Center los baja solo, junta las partes y
comprueba el SHA-256 firmado en `juegos.json` (rama `actualizaciones`). No hace falta tocar nada a mano.

Una carpeta por juego y versión: `zonacero/1.3/`.
